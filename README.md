# Pocket Money & Piggy Bank Tracker

A clean, beginner-friendly Python console application built entirely with primitive data types (`str`, `int`, `float`, `bool`). It helps track savings, calculate chore earnings, log expenses, and verify whether a savings target has been reached.

---

# Concepts Covered

This project demonstrates the core building blocks of Python:

- **String (`str`)**: Handles user names and savings goals.
- **Integer (`int`)**: Counts whole numbers, such as completed chores.
- **Float (`float`)**: Manages currency values and decimal amounts.
- **Boolean (`bool`)**: Evaluates logical conditions (goal reached or empty balance).
- **Type Conversion**: Converts user input using `int()`, `float()`, and formats outputs with `str()`.
